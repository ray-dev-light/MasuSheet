# MasuSheet Screenshots

This directory stores official screenshots embedded in [`README.md`](../../README.md) and [`README.ja.md`](../../README.ja.md):

- `masusheet-overview.png` — Light Mode workspace (English UI) showing the 15-tab Material 3 ribbon, 2-layer Canvas spreadsheet grid, XY scatter chart with live colored cell-range highlights (`I3:I22`, `J3:J22`, `K3:K22`), and cell context menu.
- `masusheet-pivot-ai-ja.jpg` — Japanese UI workspace showing an AI-generated Inventory & Reorder table with color-scale conditional formatting, a 2-level PivotTable (`発注判定` × `商品名`), the PivotTable Fields pane, and the 3-mode AI Spreadsheet Assistant.
- `masusheet-macro-dark.png` — Dark Mode workspace (English UI) showing the `Automate` ribbon tab with saved macro shortcuts and the Macro & VBA Automation Studio (recorder, VBA runner, step debugger, and natural-language converter).
- `masusheet-mobile-formula.png` — Smartphone portrait layout with the ribbon collapsed (`Show Ribbon`) to maximize grid space and live formula auto-complete (`fx Suggest`).
